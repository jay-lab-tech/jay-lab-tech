## 💡 Prinsip Engineering

> **1. Design First, Code Later** — Desain skema & API contract sebelum sentuh kode.
>
> **2. Database is the Foundation** — Skema yang buruk = utang teknis selamanya.
>
> **3. Measure Before Optimize** — Profiling dulu, baru tuning. Bukan tebak-tebakan.
>
> **4. Cache is a Feature, Not a Hack** — Redis bukan solusi instan, tapi bagian dari arsitektur.
>
> **5. Fail Loudly in Dev, Silently in Prod** — Log detail saat development, tangani rapi di production.
>
> **6. Code for the Next Developer** — Kode hari ini akan dibaca orang lain 6 bulan lagi (termasuk diri sendiri).
>
> **7. Consistency Over Perfection** — Lebih baik konsisten setiap hari daripada sempurna sekali.

## ❓ Q&A

<details>
<summary><b>Fokus utama kamu di backend apa?</b></summary>
<br>
Desain API yang clean, autentikasi yang aman, dan optimasi database. Saya suka bikin endpoint yang <i>predictable</i>, cepat, dan mudah di-maintain — bukan cuma "jalan".
</details>

<details>
<summary><b>Kenapa pilih Node.js/Express dan Laravel?</b></summary>
<br>
<code>Node.js + Express</code> untuk API yang butuh concurrency tinggi dan integrasi mulus dengan frontend TypeScript. <code>Laravel</code> untuk aplikasi yang butuh pengembangan cepat, ekosistem lengkap (Eloquent, Queue, Sanctum), dan struktur yang sudah jelas.
</details>

<details>
<summary><b>Kapan pakai PostgreSQL vs MySQL?</b></summary>
<br>
<code>PostgreSQL</code> kalau butuh fitur advanced: JSONB, CTE, window function, full-text search, dan constraint kompleks. <code>MySQL</code> kalau butuh simple, cepat, dan ekosistem hosting yang luas.
</details>

<details>
<summary><b>Gimana strategi caching kamu?</b></summary>
<br>
<code>Redis</code> untuk data yang sering diakses tapi jarang berubah — config, session, dan hasil query berat. Saya juga pakai untuk rate limiting dan background job queue. Cache invalidation selalu dipikirkan sejak desain, bukan ditambah belakangan.
</details>

<details>
<summary><b>Terbuka untuk freelance atau kolaborasi?</b></summary>
<br>
Terbuka! Untuk backend API, full stack app, atau optimasi database. Silakan hubungi lewat email atau LinkedIn di bawah.
</details>
